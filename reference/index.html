AI System Design Reference & Comparison Tables

Objective, non-promotional decision frameworks, performance trade-offs, and production checklists for system architects.

1. LLM Customization Strategy: Fine-Tuning vs. RAG vs. Long-Context Prompting

Choose the right architecture based on dynamic knowledge requirements, style control, and latency budget.

Dimension Fine-Tuning (SFT / LoRA) Retrieval-Augmented Generation (RAG) Long-Context In-Context Learning
Primary Purpose Adapt model output style, tone, format, or specialized task domain mechanics. Inject dynamic, rapidly changing external corporate knowledge. Ad-hoc analysis of large, structured documents within a single pass.
Dynamic Knowledge Updates Poor. Requires periodic re-training or continual weight updates. Excellent. Update vector indices or documents instantaneously. Immediate. Load new raw text into prompt context window.
Hallucination Risk Medium to High. Weights memorize parametric facts imprecisely. Low. Answers grounded directly in retrieved source passages. Medium. Susceptible to "lost-in-the-middle" attention degradation.
Latency & Cost Low serving latency (small prompt). High offline training cost. Medium latency (vector lookup + rerank + model generation). High serving cost & TTFT (Time-To-First-Token) scales quadratically/linearly.
Auditability & Verification Opaque. Difficult to trace exact parametric reasoning source. High. Direct attribution via metadata citations and document IDs. High. Passages reside explicitly in input prompt payload.

2. Retrieval Architectures: BM25 vs. Dense Vector vs. Hybrid Search

Evaluating lexical precision vs semantic abstraction for search systems.

Feature Lexical Search (BM25 / TF-IDF) Dense Embeddings (Bi-Encoders) Hybrid Search + Cross-Encoder Rerank
Matching Mechanism Exact term match, term frequency, inverse document frequency. Cosine similarity / inner product of dense latent vector representations. Reciprocal Rank Fusion (RRF) of BM25 + Dense, followed by Cross-Encoder.
Out-of-Vocabulary / Acronyms Handles exact acronyms (e.g. SKU codes, part IDs) effortlessly. Fails on domain-specific non-dictionary identifiers. Optimal. Lexical matches specific tokens; dense matches intent.
Semantic Understanding Zero. Fails on synonyms ("automobile" vs "car"). High. Captures conceptual intent and cross-lingual meaning. High. Combines keyword fidelity with conceptual abstraction.
Computation Overhead Extremely fast, inverted index lookup (<5ms). Fast ANN vector search (<20ms). Slower (~50-150ms due to Cross-Encoder joint attention pass).

3. Production AI System Readiness Checklist

Essential engineering criteria prior to promoting an AI service to live traffic.

1. Security & Guardrails
  • Input prompt injection sanitizer configured.
  • Output schema validation via JSON Mode or pydantic.
  • PII & sensitive credential masking active.
  • Tool calling authorization restricted to read-only scopes.
2. Monitoring & Telemetry
  • Latency tracking: P50, P95, P99 Time-To-First-Token (TTFT).
  • Token throughput & cost tracking per client/tenant.
  • Data drift tracking (Kolmogorov-Smirnov distance).
  • Faithfulness and answer relevance automated scoring.
3. Fallbacks & Reliability
  • Model API rate limit retry with exponential backoff + jitter.
  • Secondary fallback LLM routing on timeout/failure.
  • Deterministic static response fallback on outage.
  • Circuit breaker pattern for downstream tool invocation.
