LLM Architecture, Context Windows & Inference Mechanics

Large Language Models (LLMs) rely on decoder-only Transformer architectures. Optimizing inference latency, memory footprint, and token generation costs requires understanding KV caching, attention complexity, and quantization.

1. Self-Attention Mechanics

Attention maps queries $Q$, keys $K$, and values $V$ across token sequence lengths:

Scaled Dot-Product Attention Equation 
Attention(Q, K, V) = softmax( (Q * K^T) / sqrt(d_k) ) * V

2. Key-Value (KV) Cache Memory

During autoregressive generation, past key and value tensors are cached in GPU memory to avoid recomputing attention states for previously generated tokens.

VRAM Equation for KV Cache
KV Cache Size = 2 * n_layers * n_heads * d_head * seq_len * batch_size * bytes_per_element.
