Model Evaluation: Offline vs Online Metrics & Benchmarking

A model with 99% accuracy can be completely useless in production. Rigorous evaluation requires matching metric selection to real-world business objectives and class distributions.

1. Why Accuracy Misleads

In imbalanced scenarios (e.g. fraud detection where 99.9% of transactions are legitimate), a dummy classifier predicting "legitimate" for every input achieves 99.9% accuracy while detecting zero fraud.

2. Confusion Matrix & Core Metrics

  • Precision: $\frac{TP}{TP + FP}$ — Out of all samples predicted positive, how many were actually positive?
  • Recall (Sensitivity): $\frac{TP}{TP + FN}$ — Out of all actual positive samples, how many did the model catch?
  • F1 Score: Harmonic mean of Precision and Recall: $2 \cdot \frac{P \cdot R}{P + R}$.

3. ROC-AUC vs. PR-AUC

When class distribution is heavily skewed (<5% positive class), use Precision-Recall AUC (PR-AUC) instead of ROC-AUC. ROC-AUC uses True Positive Rate vs False Positive Rate, where a large negative class denominator suppresses False Positive Rate artificially.
