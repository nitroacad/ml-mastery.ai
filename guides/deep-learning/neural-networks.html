Deep Neural Networks, Backpropagation & Optimizers

Deep neural networks are composite non-linear functions parameterized by weight matrices and bias vectors. Backpropagation uses the chain rule to propagate error gradients backwards through computational graphs.

1. The Forward Pass & Activation Functions

A hidden layer computes linear transformation $z = W \cdot x + b$, followed by non-linear activation $\sigma(z)$ (e.g. ReLU, GELU, SiLU):

PyTorch Forward Pass Pattern 
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self, in_features, hidden_dim, out_features):
        super().__init__()
        self.fc1 = nn.Linear(in_features, hidden_dim)
        self.act = nn.GELU()
        self.fc2 = nn.Linear(hidden_dim, out_features)

    def forward(self, x):
        return self.fc2(self.act(self.fc1(x)))

2. Backpropagation Mechanics

The gradient of loss $L$ with respect to layer weights $W^{(1)}$ is derived using chain rule:

Chain Rule Derivation 
∂L / ∂W(1) = (∂L / ∂y_pred) * (∂y_pred / ∂a1) * (∂a1 / ∂z1) * (∂z1 / ∂W(1))
