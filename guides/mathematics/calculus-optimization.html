Calculus, Gradients & Optimization Mechanics

Optimization is the process of adjusting parameters to minimize a loss function. Multi-variable calculus provides the gradient vector that points in the direction of steepest increase.

1. The Gradient Vector ($\nabla L$)

For a scalar loss function $L(w_1, w_2, \dots, w_n)$, the gradient vector contains all partial derivatives:

Gradient Vector Notation 
∇L(w) = [ ∂L/∂w1,  ∂L/∂w2,  ...,  ∂L/∂wn ]

2. Gradient Descent Update Rule

To decrease loss $L$, parameter vector $w$ is updated in the opposite direction of the gradient by learning rate $\eta$:

Python Implementation 
# Parameter update step
learning_rate = 0.01

# W_new = W_old - (learning_rate * gradient)
weights = weights - learning_rate * grad_weights
