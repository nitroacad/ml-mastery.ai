Linear Algebra & Matrix Operations for Machine Learning

Linear algebra is the mathematical language of high-dimensional state spaces. Every dataset, token embedding, image tensor, and model parameter matrix relies on linear transformations.

1. Tensors: Data Dimensions

In computational machine learning, tensors represent N-dimensional arrays:

  • Scalar (0D Tensor): A single numerical value (e.g., loss value = 0.245).
  • Vector (1D Tensor): Array of numbers representing a point in space or feature vector (e.g., word embedding of dimension 768).
  • Matrix (2D Tensor): Table of numbers (e.g., batch of samples x feature dimensions).
  • 3D+ Tensor: Higher dimensions (e.g., [Batch Size, Sequence Length, Embedding Dim] in LLMs).

2. Dot Product & Cosine Similarity Mechanics

The dot product of two vectors $a$ and $b$ measures their directional alignment:

Python / NumPy Representation 
import numpy as np

# Define two 4-dimensional vector embeddings
a = np.array([0.5, 0.2, -0.8, 0.1])
b = np.array([0.4, 0.3, -0.7, 0.2])

# Compute Dot Product
dot_product = np.dot(a, b)

# Compute Cosine Similarity
norm_a = np.linalg.norm(a)
norm_b = np.linalg.norm(b)
cosine_sim = dot_product / (norm_a * norm_b)

print(f"Dot Product: {dot_product:.4f}")
print(f"Cosine Similarity: {cosine_sim:.4f}")

3. Matrix Multiplication ($A \cdot B$)

In linear transformations, multiplying matrix $A$ (shape $M \times K$) by matrix $B$ (shape $K \times N$) produces matrix $C$ (shape $M \times N$). This is the core computational kernel in deep learning linear layers:

Key Shape Rule
The inner dimensions must match: $(M \times \mathbf{K}) \cdot (\mathbf{K} \times N) = (M \times N)$. If inner dimensions do not match, matrix multiplication fails.

4. Knowledge Check

Concept Check: Matrix Shapes

If input tensor $X$ has shape [32, 128] (Batch Size = 32, Input Dim = 128) and weight matrix $W$ has shape [128, 512], what is the output shape of $X \cdot W$?

Correct! Inner dimension 128 matches; the resulting matrix shape takes outer dimensions [32, 512].
